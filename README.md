# 3DStat

Расширение для `Google Chrome`, `Opera` и `Firefox`, которое помогает следить за продажами на `3DDD` и `3DSky`: смотреть ключевые показатели, анализировать графики, переключать темы оформления и выгружать данные в Excel.

Текущая версия: `1.3`

## Что умеет расширение

- показывает верхние карточки со статистикой:
  - заработано сегодня
  - заработано за 7 дней
  - заработано за 30 дней
  - заработано с начала года
  - продажи `3DDD / 3DSky`
  - топ-модель за 7 и 30 дней
  - прогресс до следующего уровня
- строит график дохода за периоды:
  - `24 часа`
  - `7 дней`
  - `30 дней`
  - `Всё время`
- поддерживает несколько стилей графика:
  - классическая линия
  - плавная линия
  - столбцы
- позволяет менять темы оформления
- умеет экспортировать статистику в Excel
- содержит страницу настроек и страницу экспорта
- поддерживает локальную работу в `Chrome`, `Opera` и `Firefox`
- умеет собираться в готовые архивы для всех трёх браузеров

## Требования

- `Google Chrome` версии `114` или новее
- `Opera`
- `Firefox`
- доступ к сайту `3ddd.ru` или `3dsky.org`

## Установка для себя

Для локального использования удобнее всего загружать расширение прямо из корневой папки проекта.

### Chrome

1. Скачай или распакуй папку с расширением на компьютер.
2. Открой в Chrome страницу `chrome://extensions/`
3. Включи переключатель `Режим разработчика` в правом верхнем углу.
4. Нажми кнопку `Загрузить распакованное расширение`.
5. Выбери корневую папку проекта.
6. После загрузки в списке расширений появится `3DStat`.

### Opera

1. Открой страницу `opera://extensions`
2. Включи `Режим разработчика`
3. Нажми `Загрузить распакованное расширение`
4. Выбери корневую папку проекта

### Firefox

1. Открой страницу `about:debugging#/runtime/this-firefox`
2. Нажми `Загрузить временное дополнение`
3. Выбери `manifest.firefox.json` из корневой папки проекта

## Как открыть расширение

### Chrome / Opera

1. Нажми на иконку пазла справа от адресной строки.
2. Найди `3DStat`.
3. При желании нажми на значок булавки, чтобы закрепить расширение.
4. Нажми на название или иконку расширения, чтобы открыть popup.

### Firefox

1. Найди иконку расширения на панели браузера.
2. Нажми на иконку `3DStat`, чтобы открыть popup.

## Первый запуск

При первом открытии расширение покажет стартовый экран и предложит собрать статистику.

Что произойдёт дальше:

1. Расширение подключится к данным `3DDD` или `3DSky`.
2. Загрузит список продаж.
3. Соберёт полную статистику.
4. После завершения откроет основной экран с карточками и графиками.

Если история продаж большая, первая загрузка может занять достаточное количество времени.

## Настройки

На странице настроек можно:

- выбрать, какие 2 блока показывать сверху в окне расширения
- поменять порядок этих блоков
- выбрать цветовую тему
- выбрать стиль графика
- открыть диагностику, если что-то работает нестабильно

Открыть настройки можно:

- в окне расширения по кнопке `Настройки`
- или через страницу расширений браузера

## Экспорт в Excel

На странице экспорта можно:

- выбрать период выгрузки
- выбрать, какие листы попадут в файл
- настроить поля для листа `Продажи`
- скачать файл в формате `.xls`

Открыть экспорт можно в окне расширения по кнопке `Экспорт`.

## Сборка готовых архивов

Для себя вы можете работать из корневой папки проекта, а для передачи или публикации использовать готовые сборки из `dist`.

Собрать отдельную версию:

- `powershell -ExecutionPolicy Bypass -File .\build-chrome.ps1`
- `powershell -ExecutionPolicy Bypass -File .\build-opera.ps1`
- `powershell -ExecutionPolicy Bypass -File .\build-firefox.ps1`

Собрать все версии сразу:

- `powershell -ExecutionPolicy Bypass -File .\build-all.ps1`

После сборки появятся:

- `dist/chrome`
- `dist/opera`
- `dist/firefox`
- `dist/3dstat-chrome-v1.3.zip`
- `dist/3dstat-opera-v1.3.zip`
- `dist/3dstat-firefox-v1.3.zip`

## Если расширение не загружается

Проверь:

- что ты выбрал именно папку, где лежит нужный `manifest.json`
- что в Chrome или Opera включён `Режим разработчика`
- что в Firefox выбран правильный манифест
- что папка расширения не была перемещена или удалена после установки

Если что-то пошло не так:

1. Нажми `Обновить` на странице расширений браузера.
2. Если не помогло, удали расширение.
3. Снова загрузи его как распакованное.

## Конфиденциальность и хранение данных

Все данные `3DStat` хранятся локально в браузере пользователя. Расширение не отправляет статистику продаж на отдельные серверы разработчика и использует только прямое взаимодействие с `3DDD` / `3DSky` для получения данных.

Следует учитывать, что токен доступа и кэш статистики сохраняются локально без отдельного внутреннего шифрования средствами расширения.
